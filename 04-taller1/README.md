Taller 04 - Analizador de texto en Go

## Objetivo
Crear un programa en Go que permita analizar una cadena de texto.

## Actividades realizadas

1. Contar bytes y runas utilizando len y utf8.
2. Contar palabras utilizando strings.Fields.
3. Contar mayúsculas y dígitos utilizando unicode.
4. Contar letras con tilde y ñ utilizando strings.ContainsRune.
5. Explicar la diferencia entre bytes y runas.

## Archivo principal
- analizador.go

## Ejecución

Para ejecutar el programa se utiliza:

```bash
go run analizador.go
```

## Conclusión
Se aprendió a utilizar funciones de Go para analizar
cadenas de texto y reconocer diferentes caracteres.
