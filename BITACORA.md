# Bitácora de trabajo

## Tarea 3 – Analizador de texto en Go

### Actividades realizadas

- Creación de la carpeta `03-tarea3`.
- Inicialización del módulo Go mediante `go.mod`.
- Desarrollo del programa en `main.go`.
- Implementación del conteo de bytes y runas.
- Implementación del conteo de palabras, letras, dígitos y mayúsculas.
- Identificación de caracteres multibyte.
- Implementación de la validación del límite de 42 runas.
- Validación de argumentos y texto vacío.
- Creación del archivo README de la tarea.
- Ejecución de pruebas para validar el funcionamiento del programa.
- Actualización de la documentación del repositorio.
- Subida de los archivos a GitHub.

### Herramientas utilizadas

- Visual Studio Code
- Go
- Git
- GitHub

### Resultado

Se desarrolló un programa capaz de analizar texto desde la terminal, mostrar estadísticas de sus caracteres y validar el límite de 42 runas.
